# TechStore 🛒

A full-featured e-commerce storefront built with React.js — search, filter, sort, cart, and wishlist, all with localStorage persistence.

## Features
- Live product search and brand filtering
- Sort by price or rating
- Add to cart with quantity tracking, persists across refresh
- Wishlist toggle, persists across refresh
- Responsive dark-theme UI

## Tech Stack
React.js (Hooks: useState, useEffect, useRef) · Vite · CSS3 · localStorage API
